# 📊 E-Commerce Sales & Customer Analytics

## 📌 Project Overview

An interactive Power BI analytics project designed to analyze
e-commerce sales, customer behavior, product performance,
regional performance and returns.

The dashboard provides management with actionable insights
through interactive KPIs, charts, slicers, drill-through pages
and DAX-based calculations.

---

## 🎯 Business Objectives

- Monitor sales and profitability
- Analyze customer behavior
- Identify top-performing products
- Compare regional performance
- Analyze product returns
- Track monthly and yearly trends
- Support data-driven decision making

---

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel / CSV
- GitHub
